## Instruções de Uso

1. Duplicar o ficheiro .env.example e renomear a cópia para .env.
2. Substituir os valores falsos pelas credenciais reais no ficheiro .env.
3. Correr docker-compose up.

**Prefect 3 — Local self-hosted daily ingestion**

This project includes a minimal, self-hosted Prefect 3 setup for running a daily ingestion flow locally via Docker Compose.
